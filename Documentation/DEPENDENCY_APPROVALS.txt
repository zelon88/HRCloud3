APPLICATION INFORMATION ...
This application is designed to provide a web-interface for converting file formats on a server for users of any web browser without authentication.

FILE INFORMATION ...
v4.3.4.
This plain text file is the dependency approval record for the application itself.
It is written by Documentation/Build/hrconvert2-approvals.py. Every factual field is read from the dependency manifest & is rewritten by that tool. Every audit answer & every note is written by a person & is kept across a refresh.
The procedure these questions come from is in Documentation/ABOUT_DEPENDENCIES.txt.

HARDWARE REQUIREMENTS ...
This application requires at least a Raspberry Pi Model B+ or greater.
This application will run on just about any x86 or x64 computer.

DEPENDENCY REQUIREMENTS ...
The authoritative list of dependencies is Resources/Engine/depends.php & Resources/Contract/depends.php, the Engine's half & the application's, & nothing else. Run  php convertCore.php -v  to see what this installation has.

--About This Record--

These dependencies belong to the application rather than to any one pipeline. Removing
one does not disable a conversion type. It stops the application running at all, or
it removes a capability every pipeline relies on, such as the sandbox. Each section names
the half of the dependency manifest it is read from.
